## 💻 Featured Projects

### 🤖 Production RAG System — Ask My Docs 🔗 [GitHub](https://github.com/Kkj1203/RAG_AskMyDocs) | [Live Demo](https://rag-askmydocs.vercel.app)

- Hybrid retrieval (70% vector + 30% BM25, top-10) with LLM reranking (top-10 → top-5); session-isolated multi-PDF ingestion with 6-turn chat memory
- 5-provider LLM fallback router (Groq → OpenRouter → Gemini → OpenAI → Anthropic); Langfuse tracing: rerank p50=5.95s, total p50=11.09s
- GitHub Actions CI gate — runs token-overlap eval on every push; blocks merge if quality score < 0.4

---

### 🧬 LLM Fine-Tuning: SFT + DPO Pipeline 🔗 [GitHub](https://github.com/Kkj1203/LLM-FineTuning-LoRA)

- Fine-tuned Phi-3-mini-4k-instruct (3.8B) for JSON extraction — LoRA r=16, 0.23% trainable params; overall score 0.544 → 0.870 (+60%), format compliance 50% → 100% on AMD MI300X (bf16)
- Custom DPO training loop in pure PyTorch (500 pairs, 63s, $1.99/hr); documented negative result — domain-mismatched preference data causes task regression
- Prototyped on Colab T4 (32s, free), scaled to AMD MI300X via Docker/ROCm

---

### 🎙️ Real-Time Voice RAG Assistant 🔗 [GitHub](https://github.com/Kkj1203/Voice-RAG-Assistant)

- Voice-to-voice pipeline: Deepgram STT (3.1s) → RAG retrieval (19.9s) → ElevenLabs TTS (5.6s) → MP3; total latency 28.7s with per-stage graceful degradation
- Stateless voice middleware over the RAG API; custom ElevenLabs Voice Lab voice; benchmarked 3 local SLMs via Ollama across 5 task categories

---

### 😄 Facial Emotion Recognition using CNN (DenseNet Transfer Learning) 🔗 [GitHub](https://github.com/Kkj1203/Facial-Emotion-Recognition-CNN)

- Built a deep learning model to classify 7 facial emotions using the FER-2013 dataset
- Applied transfer learning with DenseNet169 and fine-tuning for improved generalisation
- Evaluated performance using accuracy, confusion matrix, and ROC–AUC metrics

---

### 🌱 YOLOv8-based Crop Disease Detection System 🔗 [GitHub](https://github.com/Kkj1203/YOLOv8-CropDiseasePredictor)

- Developed an end-to-end object detection pipeline for multi-class crop disease identification
- Fine-tuned YOLOv8 Nano using pretrained weights on a custom dataset (10 classes, 2,000+ images); mAP@0.5 = 0.80
- Assessed performance using precision, recall, and mAP metrics

### 📊 Vendor Performance Analytics 🔗 [GitHub](https://github.com/Kkj1203/Vendor-Performance-Analytics)

- Built Power BI dashboard tracking 5+ KPIs for vendor evaluation and decision support
